## d01_transform_split.R

(a) **Cost split.** For `G ∈ {128, 256, 512, 1024}` and `K ∈ {2, 3}`, time
`multigrain:::.gsd_boundary_table(t_look, spending, alpha = 0.025, grid_size = G)` with
`t_look = c(0.5, 1)` (K=2) and `c(1/3, 2/3, 1)` (K=3), `spending = function(a, t)
gsDesign::sfHSD(a, t, -2)$spend`, median of 5 runs (`system.time` or `bench::mark` if
installed, else `microbenchmark`-free `system.time` loops). Separately time
`multigrain:::.gsd_invert(tab$bounds[, l], grid = tab$grid, p = raw[, l])` per look for
`N ∈ {1e4, 1e5}` (raw p-values `runif`), and report per hypothesis. Derive table ms per
`gsBound1()` call (= table time / G) and inversion ms per 1e5 rows. Compare with the design
§4.1 derivation (c ≈ 1.06 ms, I ≈ 0).
**Interpolation error:** at `ϑ ∈ {−4, −2, 1}`, K=2, transform 200 random p-values (log-uniform
on `[1e-6, 0.025]`) through the G=1024 table and each coarser table; report max and median
relative error per G (design Appendix B method).
Also time one full `transform_pvalues_gsd()` at m=3, K=2, N=1e5, G=1024 (one HSD function
recycled) to anchor against the brief's 3.2 s.

(b) **Well-ordering and invertibility sweep.** For every node of `seq(-10, 2, by = 0.25)` and
every schedule in `list(c(0.5, 1), c(1/3, 2/3, 1), c(0.25, 0.5, 0.75, 1), c(0.6, 1))`, plus
the corners (ϑ=−10, t=c(0.1, 1)) and (ϑ=2, t=c(0.9, 1)): build the table at G=1024 inside
`tryCatch`; record pass/fail of `.gsd_check_well_ordered()` (it aborts inside the builder — catch
the condition and record its message) and, per column, the number of distinct positive
boundaries (`sum(!duplicated(col) & col > 0)`), its minimum over columns, and the smallest
boundary value. Also check `gsDesign::sfHSD(0.025, t, 0)$spend` is accepted (we believe yes:
linear), the identity `h_ϑ(t) = sfHSD(1, t, ϑ)$spend` and exact proportionality in `a`:
`sfHSD(1e-14, t, ϑ)$spend / 1e-14` vs `sfHSD(0.025, t, ϑ)$spend / 0.025` (relative difference).
Output a pass/fail matrix (node × schedule) and a one-line verdict: "no node in [-10, 2] fails".
If any node fails, say so prominently at the top of the output — it is a pause condition.

## d03_memory_and_copy.R

At `N_GA = 5e4`, m=3, K=2: build the working `N_GA × mK` matrix as `.gsd_kernel_matrix()` of a
transformed object subset to `N_GA` rows. `tracemem()` it; call
`multigrain:::graph_shortcut_gsd_parallel(x, 0.025, w, G, K, 2L, -1L, NULL)` once and assign two
columns (`x[, c(2, 5)] <- replacement`) once; report whether either triggers a copy (capture
`tracemem` output with `capture.output`/`sink`). Time 200 column assignments of `K` columns
vs 200 kernel calls (median); report the ratio against the 15 % threshold in the plan.
Also report `object.size()` of the matrix and the projected bank bytes
`8 * K * N_GA * sum(M_g)` for M=21, 41, 97 at `m_act ∈ {1, 2, 4}`.
