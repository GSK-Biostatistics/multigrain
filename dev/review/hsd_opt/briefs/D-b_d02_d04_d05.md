## d02_warm_start_profile.R — the measurement the local stage rests on

For each design (M0, M1, §2):
1. **Outer-loop reference.** At nodes `{-4, -3, -2, -1, 0, 1}` and seeds `{1, 2, 3}`:
   `transform_pvalues_gsd(raw, spending = list(sfLDOF, hsd_fn(g), …))` then a full default
   `graph_optimise_gsd(pv, gc, gain, stopping_rule = …, num_threads = 2)`; record
   `power$trial_success`, `hyp_weight`, `trans_matrix`, wall time. (18 runs per design.)
2. **Warm-started profile.** Resolve each of the 21 nodes with `transform_pvalues_gsd()` (one
   transform per node; cache the 21 objects or recompute — note the cost). Start at the node of
   the best seed-1 outer result; at each node walking outward in both directions: evaluate the
   previous node's refined optimum and the current overall best graph on this node's array
   (`create_obj_func_gsd()` on the full `nsim` rows with the kernel matrix from
   `multigrain:::.gsd_kernel_matrix()`), start `nloptr::nloptr()` (COBYLA, the `local_opt`
   options of `multigrain_control()`) from the better one encoded with
   `closest_graph_to_constraints()` + `create_start_params(gc, w0, G0, sum_to_one_constraint =
   FALSE)`, decode with `param_to_solution(process = TRUE)` then `repair_graph()`, evaluate;
   record gain `P̃(node)`, the number of objective evaluations (count calls in a wrapper), the
   graph. Also record the fixed-graph value `S(node)` (the overall best graph evaluated on the
   node's array).
3. **Gate table D4** per design: node, `P̃`, `S`, `max_seed Û_full`, gap = `max_seed Û_full − P̃`
   at the 6 outer nodes, the plateau of `P̃` at 5e-4 around its argmax, and the verdict: gate
   passes iff gap ≤ 5e-4 at every outer node inside that plateau. Report the gap outside the
   plateau too.
Also report: per-node profile cost (transform + COBYLA) and the total; the 7.5 reproduction
(M1: does the profile argmax move H2 toward Pocock-like spending, and the graph's w1 with it?).
