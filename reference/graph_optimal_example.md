# Optimised graph example

An example of an optimised graph with 4 hypotheses and a custom power
trial success utility.

## Usage

``` r
graph_optimal_example
```

## Format

### `graph_optimal_example`

A `multigrain_graph_optimal` object. For more details see
[`graph_optimise()`](https://gsk-biostatistics.github.io/multigrain/reference/graph_optimise.md)
