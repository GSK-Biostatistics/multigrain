# control_global can add and remove multiple options

    Code
      control_global(ctrl, pcrossover = 0.2, pmutation = 0.8, maxiter = 1e+05,
        popSize = 200, run = 200, monitor = FALSE)

      <multigrain_control>
      global optimisation:
      * pcrossover: 0.2
      * pmutation: 0.8
      * maxiter: 1e+05
      * popSize: 200
      * run: 200
      * monitor: FALSE
